# Eva Interactive — портфолио экспериментов с Canvas

Это моя личная лаборатория визуальных эффектов и симуляций на HTML/JS. Здесь собраны 28 мини‑проектов: от фракталов и фейерверков до симуляций физических процессов. Каждый проект — отдельная страница, где я пробую разные техники работы с Canvas.

Проект — моё портфолио. Код открыт для просмотра и изучения.

## Что внутри

- `index.html` — главная страница и навигация по проектам.
- `interactive/*.html` — 28 интерактивных проектов.
- `sitemap.xml` и `robots.txt` — настройка для поисковых систем.
- `yandex_*.html` — файл подтверждения для Яндекс Вебмастера (технический, не для пользователей).

## Для чего это портфолио

- Показать владение HTML/CSS/JS и работой с Canvas.
- Продемонстрировать умение структурировать проект и поддерживать документацию.

## Как запустить локально

1. Открой папку проекта в браузере.
2. Запусти `index.html`.
3. Переходи по ссылкам на отдельные проекты.

> Сайт размещён на Netlify. Сейчас новые деплои временно ограничены лимитом. Локальные файлы полностью соответствуют версии, которая будет опубликована после возобновления деплоев.
