# Eva Interactive — портфолио экспериментов с Canvas

Это моя личная лаборатория визуальных эффектов и симуляций на HTML/JS. Здесь собрана **30** мини‑проектов: от фракталов и фейерверков до симуляций физических процессов. Каждый проект — отдельная страница, где я пробую разные техники работы с Canvas.

Код открыт для просмотра, тестирования и изучения.

## Что внутри

- `index.html` — главная страница и навигация по проектам.
- `interactive/*.html` — **30** интерактивных проектов.
- `sitemap.xml` и `robots.txt` — базовая SEO-оптимизация для поисковых систем.
- `yandex_*.html` — файл верификации для Яндекс Вебмастера.

## Для чего это портфолио

- Продемонстрировать глубокое понимание Native JS (без тяжелых фреймворков) и алгоритмов Canvas API.
- Показать умение работать с анимацией, оптимизацией кадров (requestAnimationFrame) и математическими симуляциями.
- Продемонстрировать навыки аккуратной структуры проекта и ведения документации.

## Как запустить локально

Для корректной работы всех скриптов и путей рекомендуется запускать проект через локальный сервер:

1. С помощью Node.js (Live Server):
   ```bash
   npx serve .
   ```
2. Либо с помощью Python:
   ```bash
   python3 -m http.server 8000
   ```
3. Откройте в браузере адрес `http://localhost:3000` (или `http://localhost:8000`).

> **Статус деплоя:** Текущая локальная версия полностью синхронизирована с продакшеном. Основной хостинг — Netlify.
